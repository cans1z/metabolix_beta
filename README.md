# Metabolix

Учёт КБЖУ: мобильное приложение (Flutter) и веб-версия (React + TypeScript).
Сейчас это кликабельные прототипы без сервера — данные хранятся локально на устройстве / в браузере.

```
backend/   серверная часть (пока пусто)
mobile/    Flutter-приложение под Android
web/       веб-версия: Vite + React + TypeScript
```

## Веб

```bash
cd web
npm install
npm run dev
```

Откроется на http://localhost:5173. Сборка — `npm run build` (результат в `web/dist`).

## Мобильное приложение

Нужны Flutter SDK и Android Studio с плагином Flutter. Проект собирается только под Android.

```bash
cd mobile
flutter pub get
flutter run
```

В Android Studio открывайте именно папку `mobile`, а в списке устройств выбирайте эмулятор
или телефон — не «Windows (desktop)».

## Что реализовано

- вход / регистрация / восстановление пароля / «Войти через Google» — имитация, без сервера;
  гостю доступен только справочник продуктов;
- анкета при первом входе и расчёт нормы: основной обмен по Миффлину — Сан Жеору, TDEE,
  поправка на цель, доли БЖУ (30/30/40 по умолчанию, настраиваются), ручная норма;
- дневник по датам и приёмам пищи: добавление по граммам или порциям, правка, удаление,
  копирование приёма пищи на другую дату, остаток КБЖУ за день, вода;
- продукты: поиск, избранное, недавние, свои продукты, поиск по штрихкоду (код вводится вручную);
- свои блюда (рецепты) с расчётом на всё блюдо и на 100 г;
- прогресс: графики калорий / БЖУ и веса за неделю, месяц или произвольный период, средние, ИМТ;
- тёмная и светлая тема, норма воды, настройки напоминаний, экспорт дневника в CSV.

## Что пока заглушка

- сервер и синхронизация: REST API, JWT в защищённом хранилище, Google OAuth;
- сканирование штрихкода камерой и фото продуктов;
- push-уведомления (настройки сохраняются, но уведомления не отправляются);
- локальная база Hive / SQLite (сейчас — один JSON в `shared_preferences` / `localStorage`);
- экспорт в PDF; в мобильном приложении CSV копируется в буфер обмена.
